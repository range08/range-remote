# Range Remote Terms of Use

Last updated: 2026-09-19

Range Remote is an open-source remote access bridge. By operating or connecting the service, you are responsible for the computers, accounts, files, commands, and networks you authorize it to access.

## Authorized use

Only connect devices and accounts that you own or are authorized to administer. Do not use Range Remote to access third-party systems without permission, bypass access controls, distribute malware, or violate applicable law or service terms.

## High-risk capabilities

Filesystem writes and shell commands can modify or delete data. Shell access is disabled by default and should be enabled only on devices and operating-system accounts whose permissions are appropriate for remote automation.

## Availability

The open-source reference implementation is provided without a service-level guarantee. Operators are responsible for backups, monitoring, authentication configuration, and incident response for their deployment.

## Warranty and liability

The software is provided under the repository license and without warranties beyond those required by applicable law. Review changes and maintain backups before using write or shell tools on important systems.
